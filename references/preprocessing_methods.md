# 处理方法与审查

主框架是 RamanSPy `Spectrum` 和 `preprocessing.Pipeline`。A 路径保留仪器 `Dark Subtracted`，B 路径保留仪器 `BaseLine Subtracted`，C 路径从配置通道按统一参数处理。B 不是重新计算基线的原始 A；不得混为同一种处理。

默认顺序：可选且经核查的空白扣除 → RamanSPy Whitaker–Hayes 尖峰处理 → Savitzky–Golay → 基线 → 可选归一化。每阶段保存数组；不裁掉负值。处理历史记录实际参数、RamanSPy 版本、警告和时间。设置关闭时记录实际未执行，不应声称已校正。

| 方法 | 用途 | 核查 |
| --- | --- | --- |
| Whitaker–Hayes | 孤立异常尖峰 | 可能误伤真实窄峰；回看 A 和局部谱形 |
| Savitzky–Golay | 抑制高频噪声 | 窗长为采样点数，须奇数且大于多项式阶数；点距不均会改变物理平滑尺度 |
| AsLS | 不对称惩罚基线 | `lam/p` 改变宽带保留程度；宽谱带不能自动归入荧光 |
| arPLS / airPLS | 迭代权重基线 | 检查收敛警告、负峰和端点；三种方法一致也不证明峰的化学身份 |
| vector/area/max/minmax | 用户明确选择的尺度变换 | 会改变相对强度解释；不能掩盖不同采集条件 |

默认敏感性包括 AsLS/arPLS/airPLS、基线惩罚系数 0.3/1/3 倍、可配置平滑窗与峰 prominence 比例。查看敏感性表，不把单一参数下出现的弱小波峰当作新物种。敏感性变体用于数值稳定性，不作为独立重复计算标准差。

新增候选带至少应在 A 原始谱和一种合理处理下有可信证据；检查位置是否由背景、尖峰或过度处理造成。程序的候选峰表只是待审查线索，不能自动完成这项科学证据审阅。

默认 prominence 和局部 SNR 阈值均为 5 倍描述性噪声。平滑产生相关噪声，因此主处理管线将平滑前所选通道的噪声作为检测下限（归一化时同步缩放）；`noise_sigma_floor` 可配置更高下限。每条候选保存实际使用参数。仪器导出可能已经平滑，因而这个下限本身仍不是独立标定的噪声。位置邻近的 raw_supported 与方法一致性只是审查线索，不能证明所有局部最大值均为真实独立谱带。

空白首先比较。扣除要求显式 `conditions_verified: true`、一致波数轴及兼容采集/光学条件；核查积分时间、功率、光学路径和比例因子。保存扣除前后及 `background_subtracted` 数组，检查负峰、伪峰和宽带变形。缺关键元数据时必须人工核查，不能把“没有检测到不一致”等同于条件已经相同。

拟合在配置窗口比较无峰模型与 Gaussian/Lorentzian/pseudo-Voigt 的不同组分数，记录参数约束、随机种子、多起点稳定性、残差和复杂度指标。边界参数、高相关和不稳定结果应标记不可辨识。峰位、FWHM、面积是数学形状特征；模型内协方差不代表实验重复误差。

残差 lag-1 自相关绝对值大于 0.5 时抑制条件协方差不确定度，保留 `uncertainty_status` 与 `model_adequacy` 诊断。平滑和模型失配都可能造成残差相关；`status=ok` 不保证完整谱形模型成立，更不构成化学峰归属。触及组分数搜索上限时模型适用性仍未建立。

可选 PCA/NMF 先通过质量审计、统一轴并核查归一化和样本数。输出只称数学主成分/非负组分；不得等同真实物相，也不能替代峰与原始谱审查。
